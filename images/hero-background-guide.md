# Hero Background Image

## Требования к фото

**Размер:** 1920×1080 px или больше (рекомендуется 2560×1440)  
**Соотношение сторон:** 16:9  
**Формат:** JPG (высокое качество, 80-90%)  
**Содержание:** Красивый интерьер квартиры после ремонта

## Рекомендации

### Что должно быть на фото:
- ✅ Современный интерьер (гостиная, кухня, спальня)
- ✅ Хорошее освещение (естественный свет)
- ✅ Чистота и порядок
- ✅ Премиальные материалы (дерево, камень, стекло)
- ✅ Минимализм или современный стиль

### Чего НЕ должно быть:
- ❌ Людей в кадре
- ❌ Личных вещей (одежда, посуда)
- ❌ Тёмных, мрачных помещений
- ❌ Низкого качества (размытость, шум)
- ❌ Вертикальной ориентации

## Где взять фото

### Вариант 1: Свои фото объектов
- Сфотографируй лучший объект
- Используй штатив для стабильности
- Снимай при дневном свете
- Обработаю в Lightroom/VSCO

### Вариант 2: Стоковые фото (бесплатно)
- **Unsplash:** https://unsplash.com/s/photos/interior-design
- **Pexels:** https://www.pexels.com/search/interior/
- **Pixabay:** https://pixabay.com/images/search/interior/

**Поисковые запросы:**
- "luxury interior"
- "modern apartment"
- "living room design"
- "kitchen interior"

### Вариант 3: Купить фото
- **Shutterstock:** https://www.shutterstock.com (от $1 за фото)
- **Adobe Stock:** https://stock.adobe.com (от $10 за фото)
- **iStock:** https://www.istockphoto.com (от $12 за фото)

## Как добавить

1. Скачай/сделай фото
2. Назови файл: `hero-bg.jpg`
3. Скопируй в папку `website/images/`
4. Обнови страницу в браузере (F5)

## Оптимизация

Перед добавлением оптимизируй фото:
- **TinyPNG:** https://tinypng.com (сжатие без потери качества)
- **Squoosh:** https://squoosh.app (ручная настройка)
- **ImageOptim:** https://imageoptim.com (для Mac)

**Целевой размер:** 500-800 KB (не больше 1 MB)

## Примеры хороших фото

### Пример 1: Светлая гостиная
- Белый диван, деревянные полы
- Большие окна с естественным светом
- Минималистичный декор
- Растения в интерьере

### Пример 2: Современная кухня
- Белые шкафы, мраморная столешница
- Встроенная техника
- Подвесные светильники
- Остров или барная стойка

### Пример 3: Уютная спальня
- Большая кровать с красивым бельём
- Мягкое освещение (настольные лампы)
- Текстиль (подушки, пледы)
- Арт на стенах

## Настройки CSS

Если фото слишком тёмное/светлое, измени в `styles.css`:

```css
.hero::before {
    opacity: 0.4;  /* Увеличь для более яркого фото, уменьши для тёмного */
}

.hero::after {
    background: linear-gradient(135deg, rgba(0,0,0,0.6) 0%, rgba(0,0,0,0.8) 100%);
    /* Уменьши значения rgba для более яркого фото */
}
```

## Альтернатива: Градиент без фото

Если нет подходящего фото, используй просто градиент:

```css
.hero::before {
    display: none;  /* Отключить фото */
}

.hero {
    background: linear-gradient(135deg, #1a1a1a 0%, #2d2d2d 50%, #1a1a1a 100%);
}
```
