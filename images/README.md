# Папка для изображений

Сюда нужно поместить фотографии объектов:

## Структура файлов:
- project-1-before.jpg (фото ДО ремонта - проект 1)
- project-1-after.jpg (фото ПОСЛЕ ремонта - проект 1)
- project-2-before.jpg (фото ДО ремонта - проект 2)
- project-2-after.jpg (фото ПОСЛЕ ремонта - проект 2)
- project-3-before.jpg (фото ДО ремонта - проект 3)
- project-3-after.jpg (фото ПОСЛЕ ремонта - проект 3)

## Требования к фото:
- Формат: JPG или PNG
- Размер: рекомендуется 1200×800 px или больше
- Соотношение сторон: 3:2 или 16:9
- Качество: высокое

## Как добавить:
1. Подготовьте фото объектов (до/после)
2. Назовите их по шаблону выше
3. Скопируйте в эту папку
4. Откройте сайт — фото появятся автоматически в секции "Портфолио"

Подробная инструкция в README.md
